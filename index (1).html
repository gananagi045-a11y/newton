Numerical Analysis · Root Finding

Newton–Raphson Root Finder

Enter a function and an initial guess. The app differentiates f(x) automatically, runs the iteration and plots every step.

The method

Iteration formula

xi+1 = xi − f(xi) / f′(xi),   i = 0, 1, 2, …

Condition of convergence

| f(x)·f″(x) | / | f′(x) |² < 1

Problem setup

Use x as the variable. Powers with ^, e.g. cos(x) - x, exp(x) - 3x.

Try an example

Supported syntax
  • Operators: + − * / ^ and parentheses. Implicit products like 2x or (x+1)(x−1) work.
  • Functions: sin cos tan asin acos atan sinh cosh tanh exp ln log sqrt cbrt abs
  • ln(x) is the natural logarithm; log(x) is base 10.
  • Constants: pi, e. Inputs such as x₀ accept pi/2 or 1e-8.
  • Fractional powers of negative numbers (e.g. x^(1/3) at x < 0) are undefined in real arithmetic — use cbrt(x).

Graph

Scroll to zoom, drag to pan, hover the points for values. The pink point is x₀; tangent lines (dashed orange) show each step to the x-axis.
